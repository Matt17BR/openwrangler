# Native R runtime instructions

This file applies to `r/**`. Read the root policy first. Protocol and operation changes also require `src/shared/AGENTS.md`; host kernel, document, or recovery work requires `src/extension/AGENTS.md`; executable gates and public claims require their scripts and docs owners. Native R frames must never route through Python.

## Owned invariants

<!-- OW-RULE:I54 -->
54. The native R frame boundary accepts only canonical base `data.frame`, tibble, and data.table classes and preserves their exact R column semantics without a Python compatibility layer. Viewing reads bounded row/column windows from the live object without first copying the full frame. Editing takes one isolated original before the first draft. Stable positional column IDs keep duplicate and non-syntactic names unambiguous; pages reject unsupported classes, attributes, and cell types before publication. The TypeScript decoder validates every field, range, ID, projection, and typed cell before coordinator or webview state may use the page. Default `collapse::qDF()`, `qTBL()`, and `qDT()` outputs use those existing class paths without a new adapter or dependency; grouped `GRP_df` objects remain unsupported. Public documentation must distinguish source-level R tests from packaged editor acceptance and must not imply that the unfinished operation catalog, cleaned-data export, R Markdown, or Quarto paths already work.

<!-- OW-RULE:I55 -->
55. A live R notebook session owns the exact sole-open `NotebookDocument`, IRkernel object, and host-created candidate session ID captured before dispatch. Open and page results may publish only after the same document and selected kernel are revalidated. Host cancellation and deadlines never interrupt the user's kernel. An open that has crossed dispatch keeps its exact-kernel ownership until the original execution settles and one bounded close attempt runs on that kernel; terminal close never reacquires by URI. A detached request exposes its completion promise, and later requests to that kernel wait for the same promise. Once a mutation returns its own correlated response, a later cancellation or deadline may not hide the committed revision. Rename Column accepts only one exact `{id, name}` reference, uses a separate original/committed/draft state, keeps the notebook object immutable, and supports preview, apply, discard, latest-step replacement, inspection, and undo. Generated R must execute against base data frames, tibbles, and keyed data tables without changing the source. Notebook insertion uses the exact captured document, creates an `r` cell, proves the cell language and marker before success, and never falls back to the active notebook after an await. Frame-reader failures cross the kernel boundary only through the fixed, bounded diagnostic code set. Kernel restart retires every mapped session, and retired identity and cleanup-attempt bookkeeping stays bounded.

<!-- OW-RULE:I56 -->
56. A plain `.R` launch owns the exact sole-open `TextDocument`, version, and complete in-memory source captured before execution. It runs that source exactly once in a dedicated Open Wrangler `Rscript --vanilla` process whose working directory is the document's parent. Startup paths use private child environment variables that are removed before source evaluation; they may not alter `commandArgs(trailingOnly = TRUE)`. User stdout and stderr never carry protocol frames. The file transport uses one private bounded mailbox, serializes requests, and stops its owned process and removes its private root after the last session closes. Every await before publication rechecks the same document object, URI uniqueness, and version. Generated-code insertion targets only that captured in-memory document, proves the exact complete result after one `WorkspaceEdit`, and never retries a stale or indeterminate edit. Direct `.R` execution is supported only on macOS and Linux until Windows has equivalent whole-tree process ownership; IRkernel notebook support remains cross-platform. The VS Code-owned packaged R phase must cover a real `.R` command, picker, workbench, insertion, rerun, decoy-document isolation, unchanged disk sources, and terminal process cleanup without starting a second editor phase. Cursor's separate bounded compatibility seam does not repeat R operation or document semantics.
