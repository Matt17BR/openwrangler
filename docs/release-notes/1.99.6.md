# Open Wrangler 1.99.6

This preview expands native R editing and improves editor recovery in VS Code and Cursor.

- Native R now supports Formula and Format Datetime for base data frames, tibbles, `data.table`, and ordinary
  collapse frames. Preview, apply, and generated R produce the same result. Applied steps can be undone.
- Native R now supports One-hot encode and Multi-label binarize across the same frame families. Generated indicator
  columns have deterministic names and executable R, and missing or blank categories do not create outputs.
- On Linux, active R-terminal sessions can now export the committed cleaning result through the Save dialog. CSV is
  available directly; Parquet requires `nanoparquet` 0.5.1 or newer.
- R Markdown and R/Python Quarto actions are now release-tested in VS Code and Cursor on Linux.
- Fresh Python chunks in Quarto now bind the Jupyter-owned Interactive Window to the exact source before running the
  chunk once.
- Open Wrangler restores the confirmed session when Cursor retires its renderer after **Change Import Options**. The
  source is not reopened and the import change is not repeated.

Native R supports 26 of the 28 cleaning operations. Transform by example and custom code remain unavailable for R
dataframes in this preview.
