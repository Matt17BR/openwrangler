# Open Wrangler 1.2.2

Open Wrangler can now turn a trusted Pandas pickle into Parquet from the Explorer.

- Right-click a `.pkl` or `.pickle` file and choose **Convert Trusted Pickle to Parquet…**.
- Pick a separate destination; the original pickle is never changed.
- Open Wrangler shows the Python interpreter and asks before loading the file. The command accepts Pandas DataFrames
  and reports other pickle contents clearly.

Pickles can run Python code when opened, so use this command only with files you trust.
