# Open Wrangler 2.0.0

Open Wrangler 2.0.0 is the stable Pandas and Polars dataframe workbench. The stable editing claim covers only the
Pandas and Polars implementation of all 32 cleaning operations.

- A supported notebook's first dataframe result automatically upgrades after formatter setup. Named Pandas `Index`
  and `MultiIndex` row labels appear in the grid, and export offers an explicit choice to preserve or omit them.
- **Copy column** includes the header and the complete filtered and sorted column within the existing bounds. Grid
  selection is one rectangle; non-contiguous selections are not supported.
- A session can move from Editing to Viewing while its cleaning plan is empty and no draft is open. Unexpected
  workbench failures offer **Reload Open Wrangler**.
- Native R remains Preview with its native execution and generated-code catalog. A verified kernel change recovers
  the session without retrying the triggering read or mutation. Custom Code executes arbitrary R in the selected
  environment and is not a sandbox.
- DuckDB file editing remains experimental, and live DuckDB notebook relations remain viewing-only. Local PySpark 4.2
  final releases are supported as a stable viewing-only backend.
- Dependency lifecycle scripts stay disabled across contributor, CI, candidate, packaging, promotion, and release
  installs. Release credentials fail closed to the existing authenticated paths.

Open Wrangler requires VS Code 1.106 or newer. File and Python notebook workflows support Python 3.10 through 3.14.
