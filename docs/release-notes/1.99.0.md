# Open Wrangler 1.99.0

This is the first preview of native R support in Open Wrangler.

- Open base `data.frame`, tibble, and `data.table` variables from an IRkernel notebook.
- On macOS and Linux, run trusted `.R` files or supported R cells in `.Rmd` and `.qmd` documents, then choose a
  dataframe from the result.
- Clean R data with 20 operations, including filters, sorts, missing-value handling, text tools, type conversion,
  and numeric rounding. Every step shows its data changes and generated R before it is applied.
- Copy or save generated R, or insert it into the notebook or document that opened the dataframe. Local R document
  sessions opened in Editing mode can export cleaned CSV files.
- Open ordinary frames returned by `collapse::qDF()`, `qTBL()`, and `qDT()` through the existing dataframe paths.
- Fill missing values in Pandas, Polars, DuckDB, and R with a median, a most-common value, or a value entered by the
  user.
- If Cursor retires an editor while its first session message is being delivered, Open Wrangler reloads that editor
  and reconnects it to the session that is already open.

This preview does not render Quarto or R Markdown documents; it runs their supported top-level R cells in a separate
process. Direct document runs are available on macOS and Linux. R notebooks work on Windows, but cleaned-data export
from R notebooks and R Parquet export are not available yet.
