# Open Wrangler 1.99.1

This preview adds two practical ways to fill gaps and completes CSV export from R notebooks.

- Fill a floating-point column with its mean in Pandas, Polars, DuckDB, or R. Nulls and NaNs are ignored, and
  view-only filters and sorts do not change the result.
- Choose several same-type fallback columns. Open Wrangler checks them in the order shown and uses the first value
  available in each row.
- Export the cleaned result of an R notebook session as CSV through the same Save flow used by the other engines.
- Updated the R gallery and extension description so they match the behavior in this package.

This preview does not render R Markdown or Quarto documents. On macOS and Linux, it can run their supported
top-level R cells in a separate R process. R Parquet export is not available yet.
