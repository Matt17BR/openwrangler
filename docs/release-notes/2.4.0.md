Changes since [v2.3.0](https://github.com/Matt17BR/openwrangler/releases/tag/v2.3.0) improve temporal values, viewing filters and Arrow Formula arithmetic.

- Pandas and Polars correct temporal display and value choices that could lose precision or overflow.
- Pandas duration counts and selections agree across supported NumPy, Pandas and Python values, and NumPy `NaT` is consistently treated as null.
- Viewing-filter Undo preserves saved operand values.
- Pandas Formula accepts additional exact Arrow results, including large odd powers of -1, widest Decimal negation and bounded negative-scale arithmetic.

<details>
<summary>Read more: compatibility and remaining limits</summary>

Temporal selections still have precision and range limits. Unsupported selections refuse instead of matching rounded neighbors; some values remain display-only. Certain mixed custom objects and calendar or unitless durations remain restricted, and some displayed duration labels still cannot be found through value search.

Arrow Formula remains bounded by native capacity and supported operand combinations. Its result type and division rounding follow native arithmetic. Formula preserves the original source columns: Pandas dataframes retaining negative-scale Arrow Decimal columns cannot be exported to Parquet.

Regenerate affected scripts to receive the generated-code corrections. Clear and reselect saved temporal filters if earlier versions rounded their values; upgrading cannot recover lost precision.

Native R remains Preview, DuckDB remains experimental, and PySpark remains a bounded viewing-only notebook backend. See the [versioned capability limits](https://github.com/Matt17BR/openwrangler/blob/v2.4.0/docs/feature-parity.md) for supported behavior.
