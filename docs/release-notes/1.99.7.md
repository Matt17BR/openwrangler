# Open Wrangler 1.99.7

This preview completes the native R cleaning catalog and makes release packages byte-reproducible.

- Native R now supports **Transform by Example** with ordered source references and one deterministic program shared
  by live execution, saved-step replay, and generated R.
- Native R now supports **Custom Code** for base data frames, tibbles, `data.table`, and ordinary collapse frames. It
  accepts a bounded R program whose local `result` is a supported dataframe with at least one column, preserves
  supported frame metadata, and assigns stable or fresh row and column identities as the result changes. Custom Code
  requires a trusted workspace and executes arbitrary R in the selected environment; it is not a sandbox.
- All 32 operations support the normal preview, apply, generated-R, copy, and save workflow. This includes
  **Pivot longer**, **Pivot wider**, **Extract regex group**, and **Split text into columns**. Native R remains a preview
  while the complete stable-v2 installed-editor and performance evidence is reviewed.
- Generated **Strip Text** is parse-safe for default whitespace and explicit mixed control/Unicode character sets.
  **Clone Column** preserves element names and treats classed dataframe-name metadata as plain data instead of
  invoking caller-defined methods.
- Active R-terminal discovery now reconciles vscode-R's read-only dataframe metadata when an editor or filesystem
  change notification is missed, without sending code to the selected R process.
- Repeated VSIX builds from the same source now produce identical bytes across source paths, file timestamps, and time
  zones. The canonical archive is approximately 5 MB and remains compatible with ordinary VSIX readers.
