# Open Wrangler 1.2.1

PySpark notebooks now show a usable first page without counting, indexing, or caching the full DataFrame. Continue
paging to reach the exact row total. PySpark support remains experimental and read-only, and unordered Spark
DataFrames must be paged in sequence.

Cleaning-step previews now bring a newly generated column into view, including in Cursor when Code Preview changes
the layout. Clicking or scrolling cancels the automatic movement.

README and gallery screenshots now use lossless 2× images on GitHub, the Visual Studio Marketplace, and Open VSX.

For contributors, pull requests now use smaller test sets for drafts and documentation-only or package-only changes.
Ready product changes still run the complete editor, notebook, accessibility, packaging, and cross-platform gates.
Heavy local commands also run one at a time to avoid accidental memory spikes.
