# Open Wrangler 1.2.1

This update speeds up column profiles, improves large PySpark notebook sessions, and fixes generated-column
navigation in Cursor.

- Pandas profiles no longer scan ordinary numeric, boolean, date, and duration columns in Python just to count
  missing values. Profiling every column in the 1 million × 20 Parquet benchmark fell from about 21 seconds to about
  6.5 seconds.
- PySpark notebook sessions now load the first page without indexing, counting, and caching the entire DataFrame.
  The row count appears when Open Wrangler reaches the final page.
- New columns stay visible when Cursor opens Code Preview and resizes the grid.
- README and gallery screenshots now use lossless 2× captures so they stay sharp on GitHub, the Visual Studio
  Marketplace, and Open VSX.
- The README includes a direct performance comparison with Microsoft Data Wrangler 1.24.2 across Pandas, Polars, CSV,
  Parquet, notebook previews, workbench launch, and column profiling.
