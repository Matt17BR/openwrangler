Since [v2.1.1](https://github.com/Matt17BR/openwrangler/releases/tag/v2.1.1), this release repairs generated cleaning code for categorical and object-valued data.

- Polars One-hot and Multi-label code now works when every original column is dropped, including single-column inputs.
- Pandas One-hot code keeps the same floating-point category names and collision decisions as the workbench.
- Generated Pandas Pivot Wider handles mixed object identifiers and `NaT` like the workbench; Group By retains integral key values and types.

<details>
<summary>Read more: other fixes, performance, and upgrade notes</summary>

- Generated Pandas and Polars categorical code refuses results with no visible columns, matching live Preview. Empty-row inputs remain valid when a visible column survives.
- Native R One-hot and Multi-label preserve rows when replacing the only original column in a data.table. The source dataframe stays unchanged.
- Missing-value checks distinguish actual Pandas sentinels from similarly named custom values. Cell rendering recognizes native scalar types and retains nanoseconds in Pandas `Timedelta` subclasses.
- Unrelated directory changes no longer make installed Python dependencies appear missing. Hard-linked installations are supported; version, distribution-record and import-origin checks still apply.
- Pandas One-hot, Drop Missing Rows, Drop Duplicates and Mark Duplicates reuse one column-position map per operation. One-hot also checks output names before allocating each column's indicators. The [measured name-check tradeoff](https://github.com/Matt17BR/openwrangler/pull/1251) includes additional metadata and modest overhead on some accepted wide inputs.
- Generated Pandas constant Fill code omits unused statistical helpers.

Previously exported scripts do not change when the extension is updated. Reopen the dataframe and regenerate affected code with this version. If a Python notebook requests a kernel restart, restart it and rerun the dataframe-creation cells without importing `openwrangler_runtime`; open the dataframe through the Open Wrangler toolbar or variable command before importing `show` again.

Stable releases now advance the minor version, so `2.2.0` sorts after `2.1.YYYYMMDD` previews. VS Code can update preview users to this higher stable version; their preview selection still permits later `2.2.YYYYMMDD` updates. Choose the stable channel to remain on stable releases. [Installation and compatibility requirements](https://github.com/Matt17BR/openwrangler/blob/v2.2.0/README.md#install) remain in effect.

Native R remains Preview. R CSV timestamps can still lose precision and time-zone information; Parquet retains its microsecond precision checks and refusals. DuckDB file editing remains experimental, while DuckDB notebook relations and PySpark remain view-only. Windows Polars JSONL/NDJSON glob paths remain unsupported, and Arrow/Decimal arithmetic retains its documented capacity refusals. See the [versioned capability limits](https://github.com/Matt17BR/openwrangler/blob/v2.2.0/docs/feature-parity.md).
