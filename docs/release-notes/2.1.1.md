Since [v2.1.0](https://github.com/Matt17BR/openwrangler/releases/tag/v2.1.0), Open Wrangler adds Redo, Dense Rank, and Mark Duplicates.

- CSV/TSV imports preserve empty fields, whitespace, and UTF-8 text.
- Sidebar sort editing keeps unfinished input; generated code preserves notebook variable names.
- Pandas profiles keep supported large-integer counts, extrema, and sums exact.

<summary>Read more: fixes, compatibility, and upgrade notes</summary>

Redo re-executes an undone cleaning command. Dense Rank preserves tied values, and Mark Duplicates flags every member of a repeated group without removing rows.

- Import detection handles uniform CR-only line endings and UTF-8 characters split at the sample boundary.
- Filter choices no longer show stale counts. Grid focus stays aligned with copied cells, and recovery refreshes profiles with the restored grid.
- Generated Python preserves notebook input names; Custom Code retains multiline strings and comments.
- Pandas Group By avoids unnecessary object conversion for safe NumPy `int64` sums. Other integer inputs retain exact widening. Profiles of supported large Pandas integers keep exact counts, extrema and sums; unavailable approximate statistics show `n/a`.

[Choose stable or preview](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/README.md#install), or [build the current source](https://github.com/Matt17BR/openwrangler/blob/main/CONTRIBUTING.md).
Dated previews such as `2.1.20260910` have a higher numeric version than `2.1.1`. If you use a preview, select the stable version explicitly or install its stable VSIX; do not expect an automatic preview-to-stable upgrade.

- Python notebooks verify the bundled runtime before reusing it. If asked, restart the kernel and recreate the dataframe without importing `openwrangler_runtime`, open it through the Open Wrangler notebook toolbar or variable command, then import and use `show` if needed. Saved notebook previews remain readable. Windows notebooks require patched Python and the default local per-user temporary directory; see the [compatibility requirements](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/README.md#compatibility-and-limits).
- Redo history clears when the session closes or recovers, or a new cleaning-plan branch is committed.
- Re-enter Formula integer literals whose digits were already lost; updating cannot recover them. Integer and Decimal operations retain engine-specific capacity and precision limits. Extended NumPy floats that would lose display/query precision remain refused. See [numeric and operation limits](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/docs/architecture.md#engine-boundaries-and-capabilities).
- Pandas and Polars remain the stable editing engines. **Native R remains Preview**, with partial coverage. Direct `.R`, `.Rmd` and `.qmd` execution is limited to macOS and Linux; literate execution runs selected R cells rather than rendering documents. [Native R support and limits](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/docs/feature-parity.md#native-r-preview) remain explicit.
- R CSV durations retain fractional values under comma `OutDec`. Timestamp CSV output can still lose precision and omits time-zone information; the export choice explains this. R Parquet requires `nanoparquet` 0.5.1 or newer and refuses timestamps that cannot be stored exactly in microseconds.
- [DuckDB file editing remains experimental](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/docs/feature-parity.md#duckdb-experimental-file-support). DuckDB notebook relations and PySpark notebooks remain view-only. PySpark requires an existing local Classic or Connect batch session on stable/final 4.2.x; streaming and remote or authenticated clusters are unsupported.
- Windows Polars JSONL/NDJSON paths containing glob characters remain unsupported. Set `openWrangler.defaultBackend` to `pandas` in Settings, then reopen with **Open Wrangler: Open File Path**. Auto does not switch engines after a read error; Pandas may infer different types. See [file-reader limits](https://github.com/Matt17BR/openwrangler/blob/v2.1.1/README.md#compatibility-and-limits).
