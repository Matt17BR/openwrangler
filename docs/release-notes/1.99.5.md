# Open Wrangler 1.99.5

This preview changes only CI and release tooling. The extension's dataframe, notebook, and R/Python document behavior
is unchanged from 1.99.4.

- Preview and stable candidates now run Python, local R, and remote R Jupyter checks in separate matrix cells. Remote
  SSH acceptance starts alongside the platform matrix, while publication still waits for every required result.
- Candidate matrices let sibling jobs finish after a failure so editor and Docker cleanup can complete and available
  diagnostics can be retained.
- Candidate R checks can reuse a compatible dependency cache from `main`.
- Pull requests limited to registered release infrastructure now use a focused, fail-closed CI tier. Product,
  runtime, shared-workflow, and mixed changes continue to run the full matrix.
- Microsoft Marketplace recovery retries an anonymous GitHub request only when it fails before receiving an HTTP
  response.
