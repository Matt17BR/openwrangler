# Open Wrangler 2.1.0

Open Wrangler 2.1.0 fixes dataframe transformations and editor state handling, and reduces unused generated code.

- Code insertion stays bound to the notebook or R document that started the command when the active session changes.
- Native views keep their registrations while loading, preserving the first tree or Code Preview request.
- Polars Pivot Wider accepts valid column names that previously collided with internal helper columns.
- Native R live and generated medians agree for tiny and extreme values in Group By and Fill Missing Values.
- The file picker ignores unsupported values inserted manually into `openWrangler.enabledFileTypes`. A non-array
  value restores the defaults, while an empty array still disables every file type.
- Code Preview sends bounded incremental edits instead of retransmitting the full document after every change.
  Full snapshots still initialize the editor and recover synchronization.
- Generated DuckDB scripts omit unused helper functions. Pandas fill scripts omit helpers for unused fill methods.
- Cancelled or invalid step inspection explains how to show confirmed data and retry.
- Polars 1.44.0 is excluded from supported runtimes.

Source builds support Node.js 22.17 and newer 22.x releases, plus Node.js 24. Node.js 23 remains unsupported. Release
candidates audit the full Node lock, including development dependencies. Dependency updates address advisories in
browserslist, fast-uri, qs, and the remote-Jupyter test environment's Tornado package.

Pandas and Polars remain the stable editing engines. Native R remains in Preview with partial coverage. DuckDB file
editing remains experimental, while live DuckDB notebook relations and PySpark notebook dataframes remain view-only.
VS Code is the primary editor target; Cursor receives a bounded Linux compatibility check.
