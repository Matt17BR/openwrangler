# Open Wrangler 1.99.2

This preview adds more R editing and makes missing-value tools easier to use.

- Group and aggregate R data frames by one or more columns. The preview shows the changed table and generated R before
  you apply the step.
- Fill missing values within groups, interpolate floating-point gaps, or use previous and next values in an explicit
  sort order. The method list changes with the selected column type and reports how many values remain missing.
- Export cleaned R notebook and document results as Parquet when `nanoparquet` 0.5.1 or newer is available.
- Switch a live notebook variable from Viewing to Editing without losing filters, sorts, column widths, selection, or
  scroll position.
- Open a base data frame, tibble, or data.table from the selected terminal created by the official VS Code R
  extension. The Operations sidebar also lists dataframes from the active IRkernel notebook and refreshes the
  selected R session on the first click.
- Open a dataframe from an `.R`, `.Rmd`, or `.qmd` tab. Open Wrangler can use the selected R terminal or run the
  supported cells in the current document. R Markdown and Quarto now accept nested chunk options and skip valid
  `eval=FALSE` chunks that refer to external code.
- Open a `.py` file directly from its editor. Ordinary files run in Python Interactive; files divided into `# %%`
  cells run only the cell under the cursor. If Jupyter needs a kernel first, Open Wrangler waits for that selection
  before finding the resulting dataframes.
- Filter a column from its profile without losing the selected column or the visible **Clear** action.
- The README now has updated Quarto, R, Python, and workbench screenshots, plus a short performance summary linked to
  the full comparison.

R notebooks work on Linux, macOS, and Windows. Direct `.R`, `.Rmd`, and `.qmd` execution is available on Linux and
macOS; it runs supported top-level R code in an Open Wrangler process and does not render the document. Grouped
`collapse::GRP_df` and indexed collapse objects are not supported in this preview.
