# Open Wrangler 1.99.4

This preview carries forward the 1.99.3 product changes and corrects the screenshots shown on public release pages.

- GitHub, Visual Studio Marketplace, and Open VSX now use the same reviewed, immutable README product images and
  full-size gallery links.
- Preview and stable publication verify the exact release commit and every declared image before creating a tag or
  submitting to a registry.
- Open VSX recovery and Visual Studio Marketplace publication restore the exact release lockfile and run the same
  check before registry authentication.

The dataframe and R/Python workflows are otherwise unchanged from 1.99.3.
