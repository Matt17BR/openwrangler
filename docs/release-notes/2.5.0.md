Changes since [v2.4.0](https://github.com/Matt17BR/openwrangler/releases/tag/v2.4.0) add Conditional Column, qualify R notebook support and correct data import, filtering and export behavior.

- R notebook support is stable for ordinary base, tibble and data.table frames in IRkernel on desktop VS Code for Linux, macOS and Windows.
- Conditional Column creates text labels or Boolean flags from one condition, with explicit results and null support.
- DuckDB CSV/TSV imports retain literal `#` records and refuse inputs that would silently change headers or drop an irregular first record.
- Pandas exports preserve supported negative-scale Arrow Decimal values in Parquet and additional Arrow temporal values in CSV.
- Exact value filters retain Decimal and temporal boundaries, and failed replay or Viewing-mode opens preserve saved cleaning plans.

<summary>Read more: improvements and remaining limits</summary>

Generated DuckDB programs for simple column edits contain fewer helpers while retaining validation. Polars Enum equality and selected-value filters accept labels outside their categories. DuckDB timestamp grids and profiles retain nanoseconds; datetime formatting preserves native precision within its supported range. The cleaning dialog keeps keyboard access during pending previews, and reopening a saved step uses its current input columns.

R notebook support covers the [defined ordinary-frame scope](https://github.com/Matt17BR/openwrangler/blob/v2.5.0/docs/feature-parity.md#first-stable-r-notebook-scope), including supported cleaning, history, generated-code copy/save/insertion, CSV/Parquet export and restart recovery. R terminal and managed-document support remain Preview; Cursor remains experimental. Grouped/indexed R frames and additional code dialects remain unsupported.

DuckDB file editing remains experimental. DuckDB notebook relations and local PySpark notebooks remain viewing-only. DuckDB refuses CSV/TSV files beginning with a line break after an optional UTF-8 BOM, and headers containing ASCII apostrophes; Pandas or Polars may support those files.

Pandas negative-scale Decimal Parquet export preserves logical values at scale zero, including requested row labels; reopened values use Decimal objects. Native capacity and storage restrictions still apply. Some displayed temporal values cannot be selected exactly and remain unavailable for filtering. See the [versioned capability limits](https://github.com/Matt17BR/openwrangler/blob/v2.5.0/docs/feature-parity.md).

Regenerate affected scripts to receive generated-code fixes. Reopen original files and reselect affected filters where earlier versions altered imported or selected values; updating cannot reconstruct lost information.
