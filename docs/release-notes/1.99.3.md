# Open Wrangler 1.99.3

This preview fixes several notebook and document workflows that still needed a retry, and makes filters and column profiles easier to use.

- Python notebooks now show **Open in Open Wrangler** after the first dataframe result, even if the formatter starts late. Results such as `frame.head()` and `frame.tail()` open the exact live result without running the cell again.
- `.py` files now handle Jupyter's first kernel selection without losing or duplicating the source cell. Python Interactive also has its own **Open in Open Wrangler** action for dataframes already loaded in that kernel, in the native toolbar in VS Code and the editor title in Cursor.
- In `.Rmd` and `.qmd` files, **Open in Open Wrangler** runs only the chunk under the cursor. R chunks reuse the selected R session; Jupyter-backed Python chunks use their Interactive Window. Relative paths resolve from the document's folder.
- Operations now reads the dataframe list maintained by the official VS Code R extension and refreshes as that workspace changes.
- Large R dataframes no longer lose profiles or value search because of a fixed dataframe-size cutoff. Statistics are calculated in bounded chunks, and sampled results are labeled.
- R dataframes with ordinary aligned `names` attributes now open. Numeric R columns can also use Min-max scaling in a cleaning step.
- Filters can be created from a grid cell, Boolean count, category, or histogram bin. Active filters appear above the grid with remove, clear, and undo controls.
- Counts and percentages share one setting across header summaries and Column profiles. **More values…** opens the longer searchable list when the compact profile cannot show every category.

R notebooks work on Linux, macOS, and Windows. Direct whole-document R execution is still limited to local Linux and macOS extension hosts. Cursor-owned document chunks need the R, Quarto, or Jupyter extension that owns them.
